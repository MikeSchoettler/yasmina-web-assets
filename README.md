# Yasmina brand-site assets

Static content for the Yango Yasmina brand landing (`yasmina.yango.com`).

Consumed via `raw.githubusercontent.com` URLs from the LPC block:

```
https://raw.githubusercontent.com/MikeSchoettler/yasmina-web-assets/main/photos/…
https://raw.githubusercontent.com/MikeSchoettler/yasmina-web-assets/main/logos/…
https://raw.githubusercontent.com/MikeSchoettler/yasmina-web-assets/main/audio/…
```

## Layout

| Dir | What |
|---|---|
| `photos/` | Hero + scene KV WebP/AVIF (home, faith, kids, plus, voice, setup, higgs, music) |
| `logos/` | Yango Yasmina wordmarks + brand lockups (SVG) |
| `icons/` | Nav + social SVG icons |
| `audio/en/`, `audio/ar/` | Voice-demo `.wav` per language |
| `videos/` | UGC WebM (unused by current landing but kept for reuse) |
| `fonts/` | Local Latin `Yango Group Headline` WOFF2 (dev-only; LPC uses yastatic Arabic family) |
